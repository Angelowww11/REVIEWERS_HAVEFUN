POCKET SEARCH / PRIVACY

Your questions stay on your device.

Updated October 24, 2026. This page describes the Pocket Search browser extension and its online question-search version.

What is stored

The extension stores your last pasted question, selected question bank, and answer/explanation display preferences in your browser’s local extension storage. The online version stores those same preferences in local storage for this website. The extension also keeps a separate draft per browser tab in extension session storage, and removes that draft when the tab closes. These saves are not synced to Packet Party user accounts.

Where searching happens

Matching runs locally against the supplied question banks. Your pasted question is not sent to Packet Party servers, an AI service, advertisers, or analytics services. The extension includes its question bank, explanations and exhibits, and does not need a network connection to search. The online version downloads those files from this website.

Webpage access

The extension runs a keyboard listener on regular HTTP and HTTPS webpages and embedded frames to support the backtick show/hide shortcut. Host access lets it repair listeners on tab activation, page load and extension startup. It checks current tab URLs only to select eligible webpages; it does not save those URLs. It creates its floating panel only when opened. It does not extract page text, automatically read your clipboard, or record browsing history. The activeTab and scripting permissions support the toolbar action and recovery; the storage permission saves the local preferences and session drafts described above.

External links and website requests

Opening Packet Party, source code, support, or browser help follows a normal external link when you select it. Website hosting providers receive ordinary requests for pages and static files and may process technical request information such as IP addresses and browser headers. Search text is not included in those requests. Other Packet Party features, such as accounts and live rooms, have separate server interactions and are outside this extension’s local search.

Clear your saved question

Use the × button inside the question input and allow the local save to finish. Removing the extension clears its extension storage. You can clear the online version’s save by clearing this website’s site data in browser settings.

Support and changes

Report an issue through the Packet Party source repository. Future releases that change data handling will update this page.
