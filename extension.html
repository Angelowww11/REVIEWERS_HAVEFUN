A little help getting started

I already installed an older version.

Download the latest ZIP and extract it over the files in your existing extension folder. Open your browser’s Extensions page and click Reload on Packet Party. If your browser asks you to approve new site access, review it to enable the webpage shortcut. Refresh open webpages afterward.

I’m on a phone or tablet.

Use Pocket Search online. The downloadable extension is for desktop Chrome, Edge and Brave. Packet Party’s quiz app can also be added to your home screen.

Load unpacked says the manifest is missing.

Extract the ZIP first. Select the packet-party-pocket-search folder that directly contains manifest.json. Selecting the ZIP or the folder above it will not work.

Can I install it with one click from a browser store?

There is no Chrome Web Store or Edge Add-ons listing yet. The ZIP installs through Developer mode using the steps above. The online version works immediately without installation.

Why doesn’t the box appear on my browser’s settings page?

Browser settings, store pages and some built-in viewers do not allow webpage extensions. On those pages, click Packet Party’s toolbar icon to use its small separate search window.
